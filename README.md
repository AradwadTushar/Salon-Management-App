# 💈 Salon Management Desktop App

A fast and intuitive **desktop application** designed for real-world salon operations — built using Electron and optimized for **speed, simplicity, and daily use**.

---

## 🚀 Overview

This app was built for a working salon environment where:

* Speed matters ⏱️
* Minimal clicks are critical ⚡
* Staff need a simple and reliable system

It enables quick billing, service tracking, and business insights — all in one place.

---

## ✨ Core Features

### 🧾 Billing & Quick Entry

* Instant bill generation
* Multi-service selection
* Automatic total calculation
* Smart customer suggestions (phone-based search)
* Keyboard-friendly workflow

---

### 📊 Dashboard & Analytics

* Daily / Weekly / Monthly revenue tracking
* UPI vs Cash visualization (chart)
* Staff performance leaderboard
* Real-time business insights

---

### 👨‍💼 Admin Panel

* Service management (add/update/delete)
* Reports export (CSV)
* Backup & restore data
* Clear/reset database

---

### 📲 WhatsApp Integration

Send formatted bill directly to customers:

```
Hey [Customer Name], thanks for visiting 💈

Services: Haircut, Beard Trim  
Total: ₹300  
Date: 27 April 2026  

We hope to see you again! ✨
```

---

### 🎨 UI/UX

* Clean, dark-themed professional interface
* Dynamic theme support
* Smooth animations & transitions
* Designed for real-time usage (not just demo)

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, Vanilla JavaScript
* **Desktop App:** Electron
* **Database:** SQLite (better-sqlite3)
* **Charts:** Chart.js

