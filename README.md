# 💈 Salon Billing App

A simple and efficient desktop application built to manage salon services, billing, and customer communication.

---

## 🚀 Features

- 🧾 Generate customer bills instantly
- ✂️ Select multiple services dynamically
- 💰 Automatic total calculation
- 📅 Auto date & time generation
- 📲 Send bill details via WhatsApp
- ⭐ Customer-friendly message format
- 🧼 Clean and minimal UI for quick usage

---

## 📦 Tech Stack

- JavaScript (Vanilla JS)
- HTML & CSS
- Electron (for desktop app packaging)

---

## 📲 WhatsApp Integration

The app allows you to send a formatted message directly to customers via WhatsApp.

Example message:
Hey [Customer Name], thanks for visiting IronStar Salon 💈

Here are your service details:
Services: Haircut, Beard Trim
Total: ₹300
Date: 27 April 2026

We hope to serve you again soon! ✨
Please consider leaving us a review 😊


---

## 🛠️ How to Run

1. Clone the repository:



2. Navigate to the project folder:
cd ironstar-salon-app


3. Install dependencies:
npm install



4. Run the app:
npm start
